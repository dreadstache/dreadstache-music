# Dreadstache Music

Official lightweight website for Dreadstache music, releases, visual work, and forthcoming merchandise.

## Current purpose

- Give listeners verified paths to current releases
- Announce the forthcoming full site and merchandise store
- Preserve Dreadstache branding in GitHub-owned source and assets
- Connect cleanly to the wider Luc Cote portfolio ecosystem

## Hosting

GitHub Pages publishes from `main` at the repository root.

- Initial URL: `https://dreadstache.github.io/dreadstache-music/`
- Intended custom domain: `https://music.luccote.com/`

`CNAME.example` is intentionally dormant until the DNS record and Pages setting are ready.

## Source-site archive

The PNG files in `assets/images/` are the original public brand assets collected from the previous Google Site. The matching WebP files are optimized delivery copies used by this site.
